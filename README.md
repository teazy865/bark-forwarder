# Пуш в Bark

Небольшое Android-приложение вместо MacroDroid.
Читает уведомления MAX и VK и отправляет их в Bark на iPhone.

Звуки, иконки и лишние настройки не делались.

## Собрать APK

1. Установите Android Studio.
2. File → Open → папка `BarkForwarder`.
3. Дождитесь Gradle.
4. Build → Build APK(s) или Run на телефоне.

Готовый файл обычно здесь:

`app/build/outputs/apk/debug/app-debug.apk`

Установка: на Android разрешите «установку из этого источника» и откройте APK.

## Как пользоваться

1. Вставьте ключ Bark (только сам ключ, не весь URL).
2. Включите MAX и/или VK.
3. Нажмите «Включить доступ к уведомлениям» и разрешите «Пуш в Bark».
4. Нажмите «Тестовый пуш» — на iPhone должно прийти «Тест Bark».
5. Напишите себе в MAX или VK.

Приложение не хранит переписку на своём сервере. Ключ остаётся на телефоне. Уведомление уходит сразу на сервер Bark (`api.day.app`).

## Важно

- Google Play такое приложение может не принять. Раздача APK вручную.
- Телефон-почтальон должен быть включён и в сети.
- На Xiaomi снимите ограничения батареи.
- Пакеты: MAX `ru.oneme.app`, VK `com.vkontakte.android` и `com.vk.im`.
