# iPhone Pushes

Android-приложение, которое читает уведомления MAX, VK и других выбранных приложений и отправляет их на iPhone в [Bark](https://github.com/Finb/Bark).

Не хранит переписку на своём сервере. Ключ Bark остаётся на телефоне. Пуш уходит на `api.day.app`.

## Скачать

Готовый APK: [Releases](https://github.com/rewritte/bark-forwarder/releases)

Установка с Android: разрешите установку из этого источника и откройте APK.

## Как пользоваться

1. Установите Bark на iPhone и скопируйте ключ (только набор символов, без `https://api.day.app/`).
2. Откройте **iPhone Pushes**, вставьте ключ.
3. Добавьте приложения (MAX, VK, дубликат — отдельной строкой).
4. Нажмите «Включить доступ к уведомлениям» и разрешите **iPhone Pushes**.
5. Разрешите уведомления самому приложению, если Android спросит.
6. В шторке должно появиться постоянное **Running. Do not dismiss.** Его нельзя смахивать.
7. «Тестовый пуш» — проверка ключа.
8. Напишите в MAX или VK.

Иконка для Bark: нажмите строку приложения и вставьте прямую ссылку на PNG (`raw.githubusercontent.com/...png`).

## Важно

- Телефон с приложением должен быть включён и в сети.
- На Xiaomi / Redmi / POCO: автозапуск и батарея без ограничений.
- Официальные пакеты: MAX `ru.oneme.app`, VK `com.vkontakte.android`, VK Messenger `com.vk.im`. Клон добавляйте из списка приложений.
- Это не официальный клиент MAX/VK. Ответить в чат из баннера Bark нельзя.
